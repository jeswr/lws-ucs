User stories and use cases for the Linked Web Storage (LWS) spec.

Introduction

The LWS specifications aim to enable the development of web applications where data storage, entity authentication, access control, and application provider are all loosely coupled, as compared to the web of today where these are typically all tightly coupled, so changing one requires changing all, sometimes at a cost of all past data.

This document lists user stories and use-cases for the LWS specifications, as well as requirements identified as necessary to satisfy these use cases. Some use cases in this document may introduce requirements that are de-prioritized or even specifically out of scope for this Working Group. These are retained in this document to support our efforts to do the following:

  • Develop an LWS standard that enables future technologies which do meet these requirements.
  • Provide a common set of use cases to be leveraged in the development of such future technologies.
  • Develop a comprehensive view of the potential of the Linked Web technologies.
  • Clarify which use cases have been submitted, to avoid redundancy, where possible, in future use case submissions.

The use cases and requirements in this document are maintained as a machine-readable corpus: every use case and requirement is an RDF instance of the lws-ucr ontology (stored under ucr/), validated by SHACL shapes that enforce, among other things, that every requirement traces to at least one motivating use case, that actors and categories come from shared controlled vocabularies, and that every item has a stable identifier. The prose below is generated from that corpus (scripts/generate-spec-md.py); the Turtle is the source of truth. Items are marked with their lifecycle status: Accepted items restate the previously published document, while Proposed items are new submissions — triaged from open issues (see the issue-triage record) or derived from deployed applications — awaiting review.

This document is a non-normative use-cases-and-requirements Note. The uppercase [[RFC2119]] keywords in the Requirements section quote proposed requirements on the future LWS protocol — they state what the protocol under development is being asked to mandate, and impose no conformance criteria on any implementation of this document.
